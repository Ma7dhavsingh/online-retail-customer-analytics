## 📌 About The Project

The **Online Retail Customer Analytics** project is an end-to-end data analytics project focused on understanding retail business performance, customer purchasing behavior, and customer retention.

Using Python, SQL, Power BI, and Machine Learning, this project transforms raw transaction data into meaningful insights that can support better business decisions.

### 🎯 Project Objectives

- Analyze sales and revenue performance.
- Understand customer purchasing patterns.
- Identify high-value customers.
- Analyze product and country-wise performance.
- Segment customers using RFM analysis.
- Develop a customer churn prediction model.

## 🔄 Project Workflow

### 1️⃣ Python – Data Cleaning & EDA

- Data inspection and preprocessing.
- Handling missing values and duplicates.
- Identifying cancelled transactions.
- Revenue and sales analysis.
- Monthly sales trends.
- Top customers and products analysis.
- RFM customer segmentation.

### 2️⃣ SQL – Business Analysis

- Sales and revenue analysis.
- Customer performance analysis.
- Product performance analysis.
- Monthly sales trends.
- Business-oriented SQL queries.

### 3️⃣ Power BI – Interactive Dashboard

- Business KPI cards.
- Monthly revenue trends.
- Top-performing customers.
- Product performance analysis.
- Country-wise revenue analysis.
- Interactive slicers and filters.

### 4️⃣ Machine Learning – Customer Churn Prediction

**Status: 🚧 In Progress**

- Customer churn definition using a 90-day inactivity window.
- Historical customer feature engineering.
- Logistic Regression.
- Random Forest.
- Model evaluation.
- Data leakage verification.
- Explainable AI using SHAP (planned).
